# ColorCraft - Mobil Renk Seçici & Logo Tasarım Stüdyosu 🎨

Bu proje, fotoğraflardan renk analizi yaparak renk teorisine uygun paletler çıkaran ve bu renklerle anında profesyonel logolar/tasarımlar üretmeyi sağlayan bir mobil uygulamadır.

## ✨ Öne Çıkan Özellikler

### 1. 📸 Hassas Renk Seçici (Color Picker)
* **Kamera & Galeri Entegrasyonu:** Anlık çekilen veya galeriden seçilen görseller.
* **Büyüteçli Dokunma (Loupe):** Görselin üzerine dokunup parmağınızı gezdirdiğinizde piksel rengini büyüteçle gösterir ve anlık renk kodunu alır.
* **Akıllı Palet Çıkarımı:** Yüklenen fotoğraftaki en baskın 6 rengi otomatik analiz eder.
* **Renk Kodları:** HEX, RGB, HSL kodları ve tek dokunuşla panoya kopyalama.
* **Renk Teorisi & Harmoni:** Tamamlayıcı (Zıt), Benzer (Analogous), Üçlü (Triadic) ve açık/koyu ton varyasyonları.

### 2. 🎨 Logo & Tasarım Stüdyosu (İki Mod Seçeneği)
* **Basit Mod (Şablonlar):**
  * *Minimal İkon Logo*
  * *Modern Monogram Logo (Baş harfler)*
  * *Rozet / Amblem (Badge)*
  * *Kartvizit / Sosyal Medya Kartı*
  * İkon, marka ismi, slogan değiştirme ve fotoğraf paletindeki renkleri tek tıkla uygulama.
* **Gelişmiş Mod (Serbest Tuval):**
  * Katman yönetimi: Metin, İkon, Daire, Kare, Çizgi ekleme.
  * Tuval üzerinde konumlandırma (D-pad), boyutlandırma (+ / -), fotoğraf paletinden seçilen renkle boyama ve katman silme.

### 3. 💾 Dışa Aktarma & Paylaşım
* **Galeriye Kaydet:** Tasarımı yüksek çözünürlüklü PNG olarak cihaz galerisine kaydeder.
* **Paylaş:** WhatsApp, Instagram veya e-posta ile tasarımı paylaşma.
* **Palet Kodları:** Paleti CSS Variables, JSON veya HEX listesi olarak panoya kopyalama.

## 🚀 Çalıştırma

Geliştirme sunucusunu başlatmak için:
```bash
npm start
```
Telefonunuzda **Expo Go** uygulamasını açıp terminalde beliren QR kodu okutarak test edebilirsiniz.
